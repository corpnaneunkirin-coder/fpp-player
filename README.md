# fpp-player

촬영본 녹취 플레이어의 **기능 코드(템플릿)만** 올려 두는 공개 저장소예요. 녹취·영상·회차 정보는 들어 있지 않아요.

- `player.html`: 최신 플레이어 템플릿(녹취 데이터 자리는 비어 있음)
- `version.json`: 최신 버전 번호

각 회차의 녹취 플레이어 html(v11.11 이후)은 열 때 이 주소(GitHub Pages)를 확인해서, 더 새 판이 있으면 받아 두고 다음에 열 때부터 그 판으로 열려요.
원본 도구는 비공개 저장소에서 관리하고, 템플릿을 고치면 Claude가 이곳의 두 파일만 갱신해요.
